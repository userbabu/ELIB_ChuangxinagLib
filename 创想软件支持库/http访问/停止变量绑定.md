# HTTP 请求停止变量绑定

新代码可以直接使用 [取消令牌](../线程锁/取消令牌.md) 的 `绑定取消令牌()`，同时支持共享暂停、恢复与取消，不需要维护整数变量；以下为整数绑定接口。

`HTTP访问_Curl访问类`、`HTTP访问_WinHTTP访问类`、`HTTP访问_WinInet访问类` 均提供以下成员命令。

| 方法 | 参数 | 返回 |
| --- | --- | --- |
| `绑定停止变量` | 整数型，参考传入 | 绑定成功为真 |
| `绑定停止变量指针` | 整数型，变量地址；`0` 解绑 | 绑定成功为真 |
| `取上次请求错误码` | 无 | `0` 成功，`1223` 调用方取消，其余为后端错误码 |

全局命令 `HTTP_原子置停止变量(停止变量, 值)` 的第一个参数为参考整数，原子写入第二个参数并返回原值。使用该命令或 Windows `InterlockedExchange` 写入共享变量，不要跨线程普通赋值。

```易语言
.版本 2
.程序集变量 请求停止标记, 整数型
.程序集变量 Curl请求, HTTP访问_Curl访问类
.程序集变量 WinHttp请求, HTTP访问_WinHTTP访问类
.程序集变量 WinInet请求, HTTP访问_WinInet访问类

' 启动请求前执行；同一个变量可以控制多个独立请求对象。
HTTP_原子置停止变量 (请求停止标记, 0)
Curl请求.绑定停止变量 (请求停止标记)
WinHttp请求.绑定停止变量 (请求停止标记)
WinInet请求.绑定停止变量 (请求停止标记)

' 各工作线程使用各自的请求对象执行其原有访问命令。
' 停止按钮所在的线程只需执行这一条，不需要关闭句柄或强制结束线程。
HTTP_原子置停止变量 (请求停止标记, 1)

' 等所有工作线程的访问方法返回后，可检查各对象的结果。
.如果真 (Curl请求.取上次请求错误码 () ＝ 1223)
    ' 本次请求已取消，返回字节集为空。
.如果真结束

' 等所有请求返回后解绑，之后才可释放变量或对象。
Curl请求.绑定停止变量指针 (0)
WinHttp请求.绑定停止变量指针 (0)
WinInet请求.绑定停止变量指针 (0)
```

指针绑定与参考绑定指向同一类变量，指针值必须是变量地址，不是变量当前值。本库的 `_取变量地址` 接收参考变量并返回其地址，可直接调用 `Curl请求.绑定停止变量指针 (_取变量地址 (请求停止标记))`；停止时仍对原变量调用 `HTTP_原子置停止变量`。本库是 32 位库，指针参数为 32 位整数，不能传临时表达式、已经释放的内存或未对齐地址。

## 线程与生命周期约束

- 停止标记必须是自然四字节对齐、可写的 32 位整数，其存活期覆盖绑定后的所有请求，直到请求全部返回并解绑。库借用地址，不拥有这块内存，也不会自动复位。
- 只有值恰好为 `1` 才取消。已经置 `1` 时调用访问方法会直接返回，不发送新请求。一次请求观察到停止后会记住取消状态，退出重试和重定向流程。
- 请求运行期间不要将标记重新置 `0`；等全部请求返回后，才可原子置 `0` 启动下一批。多个请求对象绑定同一个标记时，这条约束适用于整批对象。
- 同一对象的方法通过临界区串行执行；不同对象可以并行请求。停止线程直接写标记，不需要获取对象锁。绑定、解绑和查询错误码应放在请求前或请求返回后，避免等待该对象的请求执行完成。
- 请求回调中不能重入该对象的访问方法或改绑停止变量。回调可以原子置 `1` 请求取消。调用方仍须保证所有使用线程结束后才析构、覆盖或释放对象。
- 复制访问类只复制配置与绑定地址；网络句柄和响应缓冲独立。复制对象同样借用停止变量，变量必须覆盖全部副本的存活请求。

## 取消结果与执行方式

取消时返回空字节集，清空本次返回头；`取上次请求错误码()` 返回 `1223`。curl 的参考参数“失败日志”同时返回 `Request cancelled (1223)`。不要把取消后的空结果当作正常网页处理。

curl 使用 multi 接口，由请求线程每轮检查停止标记，取消后移除 easy 句柄并释放资源。用户提供的进度回调仍在请求线程执行。WinHTTP 和 WinINet 在绑定变量后使用异步系统请求，调用线程等待完成通知并周期检查标记；取消只在系统调用返回后由该线程关闭请求句柄，等待 `HANDLE_CLOSING` 最终通知后才释放上下文和读写缓冲。未绑定变量时使用原有调用方式。

等待轮询间隔为 20 毫秒，这是检查间隔，不是硬实时响应承诺；操作系统调度、用户回调耗时和系统取消清理会影响实际返回时间。不要在用户回调内执行长时间阻塞操作。

整数停止变量绑定属于三个访问类实例。`网页_访问_Curl`、`网页_访问_WinHTTP`、`网页_访问_WinInet` 全局快捷请求在末尾提供可空的 `取消令牌` 参数，传入即可控制本次调用的取消、暂停与恢复；省略则不绑定，详见[取消令牌](../线程锁/取消令牌.md)。

当前库版本为 `3.18.0`，动态库和静态库均包含上述接口。全局访问的取消令牌参数追加在原参数末尾，原参数位置不变；使用新参数前需要让易语言 IDE 装载新库并重新编译调用工程。
