# 创想软件支持库

原生 C++ 支持库（`.fne`），32 位，静态 CRT，产物字符串为 GBK。
创建与维护流程见项目 skill `epl-support-lib`（`.qoder\skills\epl-support-lib\`），本目录只做这一个库的记录。

## 取消与暂停令牌

`取消令牌` 支持共享取消、暂停、恢复、可取消等待；三个 HTTP 访问类新增 `绑定取消令牌` 与 `解绑取消令牌`。外部对一个令牌调用 `取消()` 即通知所有绑定同一轮次的请求，取消时唤醒暂停等待，返回空结果和错误码1223；复制的令牌及HTTP访问类均保留共享轮次引用，无需调用方维护整数或指针。

`取消令牌.创建()` 用于重新开始一轮，取消或暂停后均可重新创建；请求需要重新绑定。三个 `网页_访问_*` 全局命令也支持末尾可空的 `取消令牌` 参数，无需访问类实例。状态、生命周期、新轮次与暂停边界，以及完整易语言示例见 [取消令牌](线程锁/取消令牌.md)。`host_cancel.cpp` 使用本地服务器验证真实网络取消、暂停恢复与并发回收，已纳入完整宿主构建。

## 请求取消

当前版本 `3.21.0`，657 条命令、25 个数据类型。三个 HTTP 访问类提供 `绑定停止变量`、`绑定停止变量指针`、`取上次请求错误码`；全局命令 `HTTP_原子置停止变量` 用于跨线程原子设置停止标记。标记置 `1` 后终止当前请求，返回空字节集及错误码 `1223`，不会复位标记或继续重试。

接口、完整示例和变量生命周期要求见 [停止变量绑定](http访问/停止变量绑定.md)。实现位于 `cxhttp_cancel.inc` 与 `cxhttp_win_async.inc`；追加接口表由 `gen_http_cancel_table.mjs` 生成，主生成器会一并调用它。

## 多线程会合

`线程会合.创建(线程总数)` 指定一轮参与人数，所有工作线程调用同一个会合点的 `等待()`：未到齐一直等待，到齐后仅最后到达者返回真，其余返回假，由业务线程执行返回退出。停止采集时调用 `取消()` 唤醒等待者，线程全部退出后才可重新创建下一轮；详见 [线程会合](线程锁/线程会合.md)。

## 同步对象按需创建

线程锁、信号量、条件变量、线程会合统一提供线程安全的 `是否已创建()`，查询不会创建对象。前三类使用幂等的 `创建()` 按需初始化，线程会合使用 `确保创建()` 防止重置正在使用或已经结束的轮次；查询、创建和销毁的生命周期保护及示例见 [创建状态](线程锁/创建状态.md)。

## 3.9.1 —— 修 超时毫秒 的「省略」被当成 0 毫秒（线程锁 / 信号量 / 条件变量 的 进入 / 等待）

易语言把被省略的可空实参传成 `m_dtDataType == _SDT_NULL` 且 `m_int == 0`。`LkMs()` 原来只看 `m_int`，
于是 **`进入 ()`（省略超时毫秒）＝ 0 毫秒 ＝ 立即超时返回假**，与命令说明「省略则一直等」正好相反 ——
用户看 IDE 的命令行提示一眼发现「返回说明和类型不符」。现在先判空值标记再判值：
**省略 或 -1 = 一直等到成功；0 = 只试一次不等待；正数 = 最多等这么多毫秒**，命令与参数的说明都按这三档写全。
回归测试在 `host_lock` 第 12 节：另一个线程省略参数时必须仍在等锁（300 毫秒后 STILL_ACTIVE）、传 0 必须 0 毫秒返回假、
持有者放开后省略参数的等待者要拿到锁；易语言侧对应 `测试源码.txt` 第 12 节（用 `等待线程(句柄, 300)` 返回假来证明"还在等"）。
同一类口子已顺带审过 HTTP访问 族：那边的超时是 `HIntAt(...) > 0` 才生效，省略与 0 同义，无此问题。

## 3.9.0 —— 线程锁 族（新增 线程锁 / 信号量 / 条件变量 三个类，共 36 行命令：27 成员 + 9 生命周期）

新目录 `线程锁\`，不依赖 curl、不依赖易语言自带锁，只用运行期解析的 kernel32 内核对象。
动机：易语言自带的锁（进入许可证 / 临界区）不记录持有者，误解锁、解别人持有的锁、销毁后再用都会直接踩内核对象，
表现是随机崩溃。本族每个入口都先验对象再验持有者，**最坏只报一条运行时错误并返回假，不崩进程**。

- `gen_lock_table.mjs`（类清单直接写在脚本里，无 json）→ `lock_ops.h` / `lock_args.inc` / `lock_cmds.inc` / `lock_impl.inc` / `lock_funcs.inc` / `lock_names.inc` / `lock_typereg.inc` / `lock_cmdindex.inc`，套路与 `http访问/gen_http_table.mjs` 一致，行基址 577。
- 三个类：`线程锁` 15 条（创建/销毁/进入/离开/尝试进入/等待/信号/唤醒全部/是否已锁定/取持有线程id/取锁定次数/取等待数量/按名取锁/置句柄/取句柄）、`信号量` 6 条、`条件变量` 6 条。
- 实现体：`cxlock_api.inc`（kernel32 运行期入口，typedef 一律 `WINAPI`）、`cxlock_core.inc`（三种对象 + 命名锁注册表 + 加解锁 + 等待队列）、`cxlock_impl.inc`（单入口 `CxLockInvoke(pRetData,nArgCount,pArgInf,nOp,nKind)` + 每条一个薄桩）。
- 口径：**递归锁**（同线程 进入 累加 取锁定次数）；**只有持有线程能 离开/信号/唤醒全部**；`等待` 自动放开锁、醒来自动拿回；
  **只读查询（取句柄/是否已锁定/取持有线程id/取锁定次数/取等待数量）对未创建对象静默返回 0/假，不报运行时错误**，动作类才报错；
  `置句柄`/`按名取锁` 让多个变量共用一把锁，靠对象里的 `nRefs` 引用计数决定谁真正销毁，解绑与析构都不会把别人还在用的锁释放掉；
  `复制` 的口径是「按源对象配置新建独立实例」（同步原语共享内核句柄必然算不清解锁配对），复制体可直接使用。
- 等待队列：每个等待者一个自动重置事件（**初始必须无信号**，否则 等待 立即返回、等于没等），先登记再放锁，不丢唤醒。
- 离线验收：`host_lock.cpp`（`run_lock_host.bat`）多线程真跑 12 节 —— 8 线程 × 20000 轮非原子累加不丢数、跨线程 等待/信号、
  超时、命名锁同址、误用不崩、销毁后重建、信号量限并发、条件变量广播；覆盖宿主 `host_cover` 只跳过三条会挂死的 `等待`（理由写在 `g_skips`）。

## 提供的方法（3.5.0）

**文本一律 UTF-8 原样进出**，不做 GBK 转换；宽文本（UTF-16）用 `字节集` 承载，惯例末尾带 `{0,0}`。
**唯一例外是 3.4 的 `Json2` 族**：为兼容 `zyJson2.51` 模块的历史行为，文本型按 GBK(cp936)、`W` 后缀按 UTF-16 字节集、`*UTF8` 按 UTF-8。

### 网络请求（2.0）

对象模型：`浏览器会话`（配置 + 连接复用）→ `浏览器请求`（单次调用参数）→ `浏览器响应`（结果）。

### libcurl 常量（3.5.0，HTTP访问 族第一步）

`http访问\gen_http_consts.mjs` 从库自带的 libcurl 8.22 头文件机械展开 **814 条**常量
（`CURLOPT_` 356 / `CURLINFO_` 99 / `CURLE_` 88 / `CURLUE_` 34 / 特性位 31 …），
四种定义形态都做了展开：`CURLOPT(name, type, num)` 宏调用、`CURLINFO_STRING + 18` 直接式、
枚举隐式自增、`((unsigned long)1) << 3` 位移与 `CURLPAUSE_RECV | CURLPAUSE_SEND` 按位或。
`*OBSOLETE*` 与废弃别名不收录。

值按 32 位有符号入库：超过 `0x7FFFFFFF` 的取补码 —— `CURL_WRITEFUNC_ERROR` → `-1`、
`CURLAUTH_ANY` → `-273`、`CURLAUTH_ONLY` → `-2147483648`（易语言整数型本来就是 32 位有符号）。

核验两道：`node http访问\gen_http_consts.mjs --verify` 把全部常量塞进 MSVC 探针逐条比
（814/814 一致；探针必须按 `(int)` 截断打印，否则这类越界常量对不上），
再由 `host_const` 从 `.fne` 自报的常量表反读一遍再比一次。

### 返回数组的命令（3.2 新增机制）

`分割文本W_数组(参数_文本, 参数_用作分割的文本, [是否移除空白文本]) -> 文本型数组` —— 切分口径与 `分割文本W` 完全一致（同一套 `CollectSplitRanges`），
区别是不再要求先声明数组变量再传 `参考`，可以直接 `计次循环(取数组成员数(分割文本W_数组(…)))` 或整体赋值给数组变量。

库内做数组返回命令的三件事（SDK `分割文本` 示例的写法）：

1. 命令表用 `CX_CMD_AR(...)`：`m_wState` 带 `CT_RETRUN_ARY_TYPE_DATA`，`m_dtRetValType` 只写**元素类型**（这里 `SDT_TEXT`），不要 `| DT_IS_ARY`。
2. 实现里只填 `pRetData->m_pAryData`，块格式 `[INT 维数=1][INT 元素数][元素指针...]`，整块与每个元素都用 `NRS_MALLOC`（`UniMalloc` / `CloneTextData`）分配 —— 交给易语言释放，别用 `LocalAlloc`。
3. 空结果返回 `NULL` 块而不是长度为 0 的块。共用的构造函数是 `uni_core.cpp` 的 `UniRetAryData()`，写回参考数组走同一个 `UniBuildAryBlock()`。

### JSON（3.4，原 `zyJson2.51` 模块的 C++ 重写）

类 `Json2`（115 条成员命令 = 构造/复制/析构 + 112 条公开方法）+ 15 个 `JV类型_*` 常量。
命令名、参数名、参数顺序、返回类型与 `zyJson2.51.e` **逐字相同**，`.局部变量 j, Json2` 之类的写法不用改。
**编码口径是例外**：为了历史兼容，本族按原版走 —— 文本型 = GBK(cp936)，`W` 后缀 = UTF-16LE 字节集（末尾 `{0,0}`），`*UTF8` = UTF-8；不适用库内「文本一律 UTF-8」通则。

- 引擎：`json_core.cpp`（节点/对象哈希表/数组、引用计数、类型强转、合并、快速排序）+ `json_parse.cpp`（宽容语法解析、路径选择、序列化、`\u` 解码与转义）。
- 命令层：`json_cmds.cpp` 单入口 `J2Invoke(op, …)`，全部实现由 `gen_json2_table.mjs` 从 `json2_api.json`（源码抽取，与 `源码txt` 逐字节核对过）生成表 + 桩。
- 语义要点：对象成员按**插入顺序**输出；重复键就地覆盖并保留首次拼写；`K`/`I`/`选择` 读不存在的键会**创建并置 null**；解析得到的容器内整数原样回放（不改写数字串）；`\/` 总是转义，`\n` 解析成 CRLF，输出不产生 `\uXXXX`；`取文本` 把 `""/{}/[]/null` 映射为空文本。
- 迁移中修掉的三个真 bug：`JvObjPut` 在 rehash 之后重复挂链导致自环（`JvObjFind` 死循环，40 成员回归用例）；`置文本UTF8` 把文本值当字节集读；`gen_static_trampolines.mjs` 的正则漏匹配 `CX_CMD_AR` 造成成员下标差一。
- 与原版的差异只在实现（C++ 取代 EPL 逐行），行为差异未知的都记在 `libs\zyJson支持库\spec-core.md` 的歧义清单 T-1…T-10，等 IDE 对照工程确认。

验证：`build_host.bat` 四个宿主全绿 —— 覆盖宿主（390 实调 + 5 条带理由跳过 == 命令总数）、宽文本宿主、`host_json`（Json2 语义断言全部通过，运行时错误 0）、网络宿主。`test_json_engine.cpp` 是引擎层 72 条断言。IDE 对照工程见 `libs\zyJson支持库\对照测试\`。

### 与模块原版的有意差异

- **原版标了弃用的方法一律不迁**（用户 2026-10-12 明确「旧版的方法移除掉不要转移 这些都是弃用的」）：
  `寻找文本W_旧版`（原版注释"旧版有BUG"）、`W2A_Point_cx`（原版"[尽量不用]"）、
  `编码_HTML实体解码W`、`编码_HTML实体解码W_单字`（原版均"[废弃 部分无法转码]"）。
  等价能力由 `寻找文本W`、`W2A`、`编码_HTML实体解码A` 覆盖，需要宽文本版就 `编码_HTML实体解码A` 再 `A2W`。
- 文本型参数按 **UTF-8** 解释（原模块按 GBK/CP936），与库内网络命令统一；`添加文本指针`（ANSI 版）仍按传入代码页（默认 936）转换。
- `文本_取中间_批量*W`：原版每次递归会对「是否区分大小写」二次取反，导致大小写逐轮交替；现按参数原意固定（真=区分）。
- `分割文本W2`：原版遇到空片段只前进 1 个字符，多字符分隔符会切出垃圾；现按分隔符长度前进。
- `到代码W`/`取代码W` 等原版不做越界检查的位置，现补了越界返回 0，避免读非法内存。
- `数值到文本W` 用 `VarBstrFromR8` 格式化（等价于 `到文本()`），不再走 CRT 打印函数。
- `Singleline` 在 VBScript.RegExp 上没有这个属性名，写入静默失败——与原版表现一致。
- 编码转换族：`编码_URL解码_JS` 原版是 `CreateObject("ScriptControl")` 跑 JS 现算，现改为自己按 decodeURI/decodeURIComponent 口径实现，**不再依赖脚本引擎注册**；`'+'` 不当空格（与 JS 一致）。
- `W` / `A` 这种单字母命令名照原版保留，**和既有模块里的同名子程序会在 IDE 里形成二义**，迁移时把同名包装子程序删掉即可。
- `网页_Cookie合并更新_内部`：原版首参 `旧Cookie` 是 `参考`（回写合并结果），现改为普通文本入参——不强制变量、可传常量，合并结果只走返回值。
- `网页_访问_Curl` 的 `代理连接失败自动重试`：原版标了 `参考`，现改为普通 `逻辑型`（可空、不强制变量）。实现一直按值读这一位，标 `参考` 时交到的是变量地址、判不等 `BL_TRUE`，代理失败重试实际从未生效；改完才真正生效。
- 只读入参一律不再强制变量（原版标成 `参考` / `数组传址`，实现却只读不回写）：`压缩亚马逊页面数据` 的 `要压缩的数据` 改普通 `字节集`；Json2 的 `置文本数组` / `置文本数组W` / `置文本数组UTF8` / `置数值数组UTF8` / `置整数数组UTF8` / `置逻辑数组UTF8` 的数组参数改 `AS_RECEIVE_ARRAY_DATA`，可直接传数组字面量。真出参（`返回头`、`失败日志`、`返回文本码`、`返回请求头文本`、`起始查找位置`、`起始位置`、`参数_错误代码/位置`、`参数_返回的文本数组`、`取所有值` 的 `参数_路径`、`参数_仍在运行数` 等）与对象/令牌参数（`停止变量`、`源对象`、`源正则`、`取消令牌`、`参数_变量`）保持 `参考` 不变。

## 编译与落库

```
cd libs\创想软件支持库
cmd /c build.bat          :: 编 out\cxsoft.fne + cxsoft_static.lib，自动拷到 <易语根>\lib\ 与 static_lib\
cmd /c build_host.bat     :: 离线跑三个宿主（覆盖 + 宽文本/正则/编码转换 + 网络），不需要易语言
cmd /c install_to_epl.bat :: 只落库；也可带参数从发布暂存目录落库（见下）
```

落库是**自动且幂等**的：`build.bat` 每次编完自己拷；字节相同直接 `[SKIP]`，不同才覆盖并用 `fc /b` 复核；
`.fne` 被 IDE 锁住时重试两次后落一份 `.new` 并打 `[PENDING]` 显式提醒，不会假装成功。
`发布\<包目录>\mkzip.bat` 打完两个 zip 会顺手调它（参数指向 `stage\lib` 与 `stage\static_lib`），
所以**发布即落库，不必再手工复制**。剩下唯一的人工动作：IDE 若开着，重启一次才会加载新产物。

要求：本机 VS 的 32 位 `vcvars32.bat`（当前 `C:\Program Files\Microsoft Visual Studio\18\Enterprise`，换机要改各 bat 里的 `set VCVARS=`）。关键开关：`/MT`、`/source-charset:utf-8 /execution-charset:gbk`、`/D__GCC_`、`/wd4828 /wd4838`。
`build.bat` 会同时把 `libcurl-impersonate.dll` 拷进 `lib\`——**网络命令依赖它**，`.fne` 依次在自己的模块目录、宿主 exe 目录、系统路径找它。

## 静态编译（2.0 起支持）

`build.bat` 先调 `build_static.bat`：同一份 `lib.cpp` 加 `/D__E_STATIC_LIB /D_LIB` 再编一遍，`lib.exe` 打成
`out\static\cxsoft_static.lib` 并自动拷到 `<易语根>\static_lib\`。要点：

- 静态模式下只保留命令实现：`LIB_INFO`、命令/参数/类表、`GetNewInf`、`DllMain` 与三个 `NL_GET_*` case 全部用 `#ifndef __E_STATIC_LIB` 排除。
- 实现都在 `namespace cx` 里（内部链接进不了 .lib），文件末尾由 `gen_static_trampolines.mjs` 按 `g_commandFuncNames` 生成 395 个 `extern "C"` 转发，并按命令表重算 9 张类成员下标表（`g_*CmdIndex`）。**改完命令表必须重跑该脚本**：漏跑则静态链接缺符号，表内删/插命令则类里找不到成员命令。
- 校验：`dumpbin /LINKERMEMBER:1 out\static\cxsoft_static.lib` 里 395 个名字齐全、且不含 `_GetNewInf`；`dumpbin /SYMBOLS` 的 UNDEF 只该剩 `__imp__*` 与 VC6 CRT 自带的 `_memcpy/_memmove/_memset/_strncmp/_strrchr/_stricmp 系/_fopen/_fclose/_fwrite/_rand/_srand/_strtod/__fltused`（`cmd /c dump_static.bat` 直接导出来看）。
- 静态编译出的 EXE 不再需要 `.fne`，但 **`libcurl-impersonate.dll` 必须放在 EXE 同目录**（静态模式下没有 `.fne` 目录可参照）。

## 易语言里怎么用

1. 「工具 → 支持库配置」勾选**创想软件支持库**（只有首次勾选那一次需要重启 IDE）。命令面板里按类别分成 测试 / 网络请求 / 宽文本 / 正则表达式 / 编码转换 五组。
2. 网络：建三个局部变量 `浏览器会话` / `浏览器请求` / `浏览器响应`；会话上设型号与代理，请求上设网址与正文，`会话.执行(请求, 响应)` 后用 `响应.取状态码()`、`响应.取响应文本()` 取结果。
3. 宽文本/正则：变量类型取 `宽文本类`（可直接把 `字节集` 当宽文本传给全局命令）；正则用 `类_正则表达式类W` 或四个 `类_正则表达式_*` 里最顺手的，表达式与文本都给宽文本 `字节集`。
4. 编码转换：宽文本进出用 `W`/`A`（或 `A2W`/`W2A`），跟 UTF-8 之间用 `W2UTF8`/`UTF82W`，跟 GBK 之间用 `UTF82A`/`A2UTF8` 或 `编码_utf8到gb2312`/`编码_gb2312到utf8`。

## 本机踩过的坑

- `include\lib2.h` 里 `PFN_ON_NOTIFY_UNIT` 的 typedef 带默认参数 `= 0`，现代 MSVC 报 C2383；本地头已去掉，重新从 SDK 拷贝后要再改。
- 不要 `#include <mtypes.h>`（与 `windows.h` 冲突），本库只补 `DATE`/`DOUBLE`/`FLOAT`/`INT64` 四个 typedef。
- `cl` 的对象目录开关是 `/Fo`，`/Fout\` 会被解析成目录 `ut\`，要写 `/Foout\`。
- 命令返回文本必须用 `NRS_MALLOC` 复制（`CloneTextData`），不能返回静态缓冲区或 `LocalAlloc` 指针。
- `NL_GET_CMD_FUNC_NAMES`（14）返回函数名串数组，顺序同命令表。
- **命令表 / 实现表 / 函数名表必须同长同序**：`static_assert` 只兜得住同长，错位要靠宿主按命令名的语义断言发现（见上）。
- **表的中间删/插一条命令，会把后面所有命令序号整体挪位**，而 9 张类成员下标表 `g_*CmdIndex` 存的是绝对下标 —— 漏改就是「类型 N 里找不到命令「…构造函数」」，编译期一点迹象没有。现在 `gen_static_trampolines.mjs` 会按 `g_commands` 自动重算它们（成员命令以「…构造函数」分块）。
- **curl 选项号必须逐个对带头文件**：`ACCEPT_ENCODING` 是 10102（不是 10119）、`HEADERFUNCTION` 是 20079（不是 20029）。抄错不报错，只是选项静默失效（前者导致 br 正文没解压，被 UTF-8→GBK 转码压成 3 字节）。
- `curl_easy_escape` 在这个 8.22-impersonate 上对刚 `easy_init` 的裸句柄返回 NULL，URL 编解码改为自己实现。
- 回调里对结构体 8 字节字段（`INT64`）的自增实测不生效（同位置的 `int` 字段写入正常，原因未彻底定位），`取下载字节数` 改为事后测量：内存模式取正文长度，落盘模式取文件大小。
- 二进制正文不能无条件 UTF-8→GBK：`MultiByteToWideChar` 不带 `MB_ERR_INVALID_CHARS` 会丢弃非法序列。
- `build.bat` / 单文件探针里的中文会把 cmd 与 cl 的解析打断（UTF-8 中文注释含 `0x5C` 会被 GBK 当续行符吞掉下一行 `#include`）——批处理保持纯 ASCII，临时探针也带上 `/source-charset:utf-8 /execution-charset:gbk`。
- 易语言 IDE 开着时 `.fne` 被占用，覆盖会失败并退出码 1；关掉 IDE 重跑。
- 静态 `libcurl-impersonate.lib` 缺 c-ares / libcrypto 依赖，链接不过；本库改为运行时 `LoadLibrary`。

- **shlwapi 只导出 `StrRStrIW`/`StrRStrIA`，没有 `StrRStrW`**：区分大小写的反向查找改成自己正向扫到最后一次命中。
- **易语言静态编译用 VC6 的链接器与 CRT**：`_snwprintf`/`swprintf` 会引出 `___stdio_common_vswprintf`，`_stricmp` 会引出 `__stricmp`，VC6 都没有 → 数值格式化改走 `VarBstrFromR8`，大小写无关比较用自带的 `CxAsciiCmpI`；`wcsstr`/`wcstod`/`wcstol` 同理换成自实现或 UTF-8 + `strtod`。
- **`VBScript.RegExp` 的 CLSID 是 `{3F4DACA4-160D-11D2-A8E9-00104B365C9F}`**，`{3B416264-...}` 是类型库号，用它 `CoCreateInstance` 直接 `REGDB_E_CLASSNOTREG`。
- **`参考` 参数在 `MDATA_INF` 里放的是变量地址**（`m_ppBin`/`m_pInt`/`m_ppAryData`），按值读会拿到指针的指针：读到假数据、写回时 `free` 掉一个假地址直接堆损坏。文本处理类命令里 `文本_替换_正则W`、`格式化宽字符W2` 走 `ViewFromRefBin`。
- **`static_assert` 只能兜住"三张表同长"，兜不住同序**：3.1 加编码转换时把 `宽文本_处理末尾空字符` 排在三条 URL 命令之后、实现表却按 `UcWideTrimNull` 在前，结果 `编码_URL编码W` 返回了宽文本、`宽文本_处理末尾空字符` 返回了 1 字节。只有**按命令名逐个断言返回值语义**的离线宿主能发现这类错位（`HOST_TRACE=1 out\host_uni.exe` 会打印每条被调命令的序号与名字）。
- **宿主调用命令要按命令表声明的参数个数补齐**：实现是按表读 `pArgInf[k]` 的（`文本_取中间_批量W` 读第 13 个参数），宿主只传 5 个就是越界读栈——换一版编译器/多几个局部变量就崩。`host_uni.cpp` 的 `Call()` 现在按 `m_nArgCount` 自动补 `_SDT_NULL`。
- **`.fne` 每次链接的 md5 都会变**（PE 头里有 TimeDateStamp），所以"hash 和已装的不一样"不代表内容变了；落库脚本的幂等只能判"是不是我这次编出来的那份"。要比内容请比 `.obj` 或导出符号表。
- **换版本不需要重启易语言 IDE（实测），但 IDE 开着会锁 `lib\*.fne`**：此时 `copy` 必失败，脚本重试两次后把新文件落成 `cxsoft.fne.new` 并打 `[PENDING]` —— 看到它就关掉 IDE 再跑一次 `install_to_epl.bat`。只有第一次勾选 / 取消勾选支持库才需要重启 IDE。
- **`DTM_SYS_DATA_TYPE_MASK` 是标志位（0x80000000）不是掩码**：`(x & DTM_SYS_DATA_TYPE_MASK) == (SDT_BIN & DTM_SYS_DATA_TYPE_MASK)` 对任何系统类型都成立，判类型一律用 `==` 或 `LOWORD()`，否则宿主里"文本/字节集"分支会全部误命中。
- **数组参数怎么声明**（SDK `docs.txt` 官方例）：`ARG_INFO.m_dtType` 只写**元素类型**（不带 `DT_IS_ARY`），数组性写在 `m_dwState`（`AS_RECEIVE_ARRAY_DATA`=只读传值 / `AS_RECEIVE_VAR_ARRAY`=参考交地址）。表里写成普通 `字节集` 而实现按数组读，IDE 里必崩——`数组_打乱数组_文本W`、`文本_替换子文本_数组W` 各有一处，是覆盖宿主抓出来的。
- **覆盖类冒烟测试别喂假指针**：`置指针` 这类命令会把传入的"地址"存进对象，之后任意一条命令解引用它就炸；扫描一律传 0，真指针正例交给 `host_uni`。
- **`TextArg` 造的参数不能 `FreeBinArg`**：`m_pText` 和 `m_pBin` 是同一个 union 字段，`FreeBinArg` 会 `free` 掉一个栈数组，表现为下一段代码莫名崩溃。
- **HTML 实体解码这类"按 `&` 切段"的循环必须保证每轮至少前进 1 个字符**：未知实体（`&notreal;`）解析失败时内层 `while (… != '&')` 一步都不走，`i = nRun` 就原地死循环（实测把宿主挂死，不是崩溃，很容易误判成网络命令卡住）。
- `NRS_FREE_ARY(2023)` 的 `dwParam1` 是数据类型、`dwParam2` 才是数组数据指针；宿主按错参数释放会直接破坏堆。
- 数组元素写回：先 `Clone*` 出副本 → `NRS_FREE_ARY` 旧块 → `NRS_MALLOC` 新块 `[1][成员数][元素指针...]` → 写回 `*m_ppAryData`，顺序不能换。
- `include\cx_uni.h` 里 `MAKELONG(类型序号,0)`
- **`/D__GCC_` 会把 SDK 头的 `#pragma pack (1)` 一起关掉**：`MDATA_INF` 从 12 字节变 16，参数数组按 16 取 → 第 2 个参数起全是垃圾，而单参数命令看着完全正常、离线宿主也自洽通过。本地 `include\lib2.h` 已改成无条件 `pack(push,1)`，并在头里加了 `static_assert(sizeof(MDATA_INF)==12)`；改编译开关前先跑 `cmd /c sz.bat` 看这个数。详见 skill `references/cpp-fne.md` 坑 27。
 用于对象参数/返回值；`HIWORD` 必须为 0。
- **宿主夹具 `W(...)` 以 0 结尾**：它是变参 + 哨兵，末位漏写 `0` 会一路 `va_arg` 读栈，把栈垃圾当字符写进字节集（表现为"替换/匹配结果前面都对、后面跟一串乱码"，看着像库的 bug，其实是测试数据坏了）。同一段里要两份独立宽文本用 `WB("utf8")`，别连着调 `W()`（共用一块增长区，长度会互相踩）。
- **bat 里判宿主要用精确比较，不能用 `if errorlevel 1`**：宿主崩了返回的是负码（如 `0xC0000005` 截断成负数），`if errorlevel 1` 是"≥1"，会把崩溃当成功放过。`build_host.bat` 用 `:chk`（`if "%ERRORLEVEL%"=="0" exit /b 0`，否则原样打码并失败退出）。
- **"改了没生效"先看命令表变没变**：只改实现（表不变）替换文件即可；一旦增删过命令，序号全挪位，IDE 进程里还是启动时装的那份镜像 + 工程里存的旧序号，表现就是某条命令返回空且不报错。判据：`fc /b out\cxsoft.fne <易语根>\lib\cxsoft.fne` 只差 TimeDateStamp 两处 → 磁盘上已是最新，问题在装载；`lib\cxsoft.fne.new` 还留着 → 上次落库被 IDE 锁住没顶上。处理：关 IDE → `install_to_epl.bat` → 开 IDE → **重新编译整个工程**。
