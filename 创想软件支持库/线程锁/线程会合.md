# 线程会合

`线程会合` 用于已知线程总数的一轮同步：先到的线程阻塞，人数到齐时，仅最后到达的线程从 `等待()` 返回真，其余线程返回假。调用方据此让其他线程结束，只由最后一个执行汇总或下一步操作。

## 接口

| 方法 | 参数 | 行为 |
| --- | --- | --- |
| `是否已创建` | 无 | 线程安全地查询是否已配置线程总数；构造后未配置、销毁后为假，到齐或取消后仍为真 |
| `确保创建` | 线程总数，整数，必须大于 0 | 原子检查并在未配置时配置；不重置已有轮次，既有线程总数不一致时报告错误 |
| `创建` | 线程总数，整数，必须大于 0 | 设置一轮会合；成功返回真；上一轮仍有等待调用没有完成时拒绝重建并报告运行时错误 |
| `等待` | 无 | 人数未到齐一直等待；最后到达者返回真，其余返回假；本轮已到齐或已取消时，晚到或重复调用返回假 |
| `取消` | 无 | 取消尚未到齐的一轮并唤醒等待者，全部返回假；已到齐、已取消或未创建时返回假 |
| `取到达数量` | 无 | 本轮已到达会合点的人数，仅供观察，不能据此自行决定谁执行后续操作 |
| `是否已完成` | 无 | 本轮是否已经到齐，不代表工作线程已退出或后续汇总已完成 |
| `是否已取消` | 无 | 本轮是否已经取消 |
| `销毁` | 无 | 解除本变量的引用；最后一个变量释放时取消尚未完成的会合，内部事件在等待调用结束后释放 |

## 五线程采集示例

所有线程必须使用同一个全局会合对象，或使用该对象的副本。复制对象共享会合状态，并独立持有引用，不会分成不同的会合点。

```易语言
.版本 2
.全局变量 采集会合点, 线程会合

.子程序 开始一轮采集

' 在启动任何工作线程之前创建；必须检查创建是否成功。
.如果真 (采集会合点.创建 (5) ＝ 假)
    返回 ()
.如果真结束
' 随后启动五个采集工作线程，各线程完成自己的采集任务后调用下面的会合逻辑。

.子程序 工作线程末尾

' 此前完成本线程负责的采集、保存结果和资源清理。
.如果真 (采集会合点.等待 () ＝ 假)
    返回 ()
.如果真结束

' 只有最后一个到达的线程能够执行这里。
' 在这里汇总本轮结果或通知主界面本轮数据已准备好。

.子程序 停止采集时取消会合

采集会合点.取消 ()
' 同时设置采集停止标记、取消网络请求，并等待各工作线程正常结束。
' 所有工作线程退出后，才能重新 创建(5) 开始下一轮，或 销毁()。
```

线程总数为 1 时，唯一一个调用立即返回真；总数为 5 时，先到的四个调用保持等待，第五个到达时唤醒它们，只有第五个返回真。会合不自动开启下一轮，同一轮最多返回一次真。

## 线程与停止约束

- 每个参与线程每轮调用一次 `等待()`，且必须能走到该调用。启动失败、线程提前退出或异常导致人数不足时，等待不会自行超时，需要控制线程显式调用 `取消()`。
- 到齐与取消由同一把内部临界区决定先后：取消先发生则这一轮没有任何线程返回真；到齐先发生则仍只有最后到达者返回真，之后的取消返回假。
- 工作线程在进入 `等待()` 前，必须释放其他参与者到达会合点所需的锁，否则可能互相等待。
- 停止按钮调用 `取消()`，不能强杀等待线程，也不能在运行中重置许可证。操作顺序为取消会合与请求、等待工作线程退出，再释放对象或启动下一轮。
- `等待()` 不是等待线程句柄结束：最后一个返回真时，只保证所有参与者都已进入会合点，不保证其他线程已经退出。最后到达者不能立即销毁其他线程仍可能使用的数据。
- 业务代码若要让整个工作线程结束，必须在 `等待()` 返回假时执行线程入口的 `返回()`；仅从嵌套子程序返回不会自动结束外层线程。
- 状态查询、创建、确保创建、复制、取消、销毁通过生命周期锁保护对象槽；`等待()` 在该锁内取得内部引用后再阻塞，不会在读到指针与增加引用之间被销毁。正常业务仍应先取消、等所有工作线程结束，再由控制线程释放变量或开启新一轮；不要在工作线程将要执行等待前主动销毁会合点。
- 类内部只保护会合计数和状态，采集结果容器、任务队列等共享业务数据仍应由各自的同步机制保护。

## 实现和验证

内部使用临界区保护计数与轮次状态，手动复位事件负责唤醒整组等待者，避免最后一个到达者发出通知时其他线程尚未进入系统等待而丢失唤醒。构造函数只创建控制块，必须显式调用 `创建(线程总数)` 才开始一轮。

原生实现位于 `cxjoin_core.inc`，命令、类型和成员索引由 `gen_join_table.mjs` 生成，全部命令追加在总表末尾。`host_lock.cpp` 第 13 节通过真实对象构造/复制/析构和多个线程验证人数不足阻塞、最后一个唯一继续、取消、复制共享、销毁期间唤醒、单线程以及 100 轮到齐/取消竞争。

按需初始化和创建状态的完整规则见 [创建状态](创建状态.md)，追加状态接口由 `gen_sync_state_table.mjs` 生成。
