# 创想AH会员框架 · 对接说明

支持库：`cxah.fne`（32 位，静态 CRT，无第三方 DLL）｜后端：`php/`（统一 JSON 协议）
命令表 GUID：`E0817B3362096FA711BF8F50631378D7`（发布后不可变）

## 1. 最小接入（三步）

```
会员_初始化 (接口地址, 产品类型, 代理KEY, 机器码, 程序版本, 程序MD5, 系统版本, 协议密钥, 登录邮箱, 超时毫秒, 调试模式, 允许退出账号)
会员_显示注册窗口 (0)          ' 登录/注册/续费/换机一体，返回真=已拿到授权
会员_发送退出事件 ()           ' 软件关闭前
```

机器码、程序 MD5、系统版本、协议密钥**必须由易语言侧在初始化时传入**——库内不生成机器码、不读自身文件，这些是旧模块里宿主本来就该提供的信息。

`协议密钥` 要等于后端 `php/app/config.php` 的 `app_secret`，否则所有请求返回 `1002`。

## 2. 文本编码约定

支持库边界上的文本**一律 UTF-8 原始字节**，库内不做 GBK 转换。GBK 的易语言工程里中文要转一次：

```
到文本 (编码_Utf8到Ansi (到字节集 (会员_取OEM信息 (“soft_name”))))
```

邮箱、机器码、日期、功能码是纯 ASCII，可直接用。`易语言兼容层.e.txt` 已把这层包装成 `本地文本()`。

## 3.5 会员管理 类（把上面这些包成一个对象）

全局命令是给「一个进程一套授权」的老式写法用的；工程里想要一个能传来传去的对象，就用类 **会员管理**：

```
.局部变量 会员, 会员管理
.如果真 (会员.初始化 (#服务器地址, #产品类型, #渠道KEY, 取本机机器码 (), #版本, 取程序MD5 (), #系统版本, #协议密钥) ≠ 0)
    返回 ()
会员.绑定事件窗口 (取窗口句柄 (), 1024)
会员.启动自动刷新 (300, 取窗口句柄 (), 1024)
.如果真 (会员.是否已授权 () 为假)
    会员.打开会员窗口 (0)
调试输出 (会员.取账号 (), 会员.取到期时间 (), 会员.取到期剩余天数 (), 会员.取上下文文本 ())
```

- 方法名与上面全局命令一一对应，只是去掉了 `会员_` 前缀，参数顺序不变；
  多了 `打开会员窗口 / 打开序列号窗口 / 打开用户中心 / 打开换机窗口` 四个界面方法。
- **类没有「属性」可写**（易语言只有可视化组件才有属性面板），所以授权上下文全部是 `取…()` 方法；
  要一次拿全就用 `取上下文文本()`，返回一段 JSON（账号、到期时间、状态、选配功能、附加信息、IP 都在里面）。
- 对象只带两件事：**事件往哪儿发**、**自动刷新是不是它起的**。授权数据仍是进程内单例，
  所以两个对象变量看到的是同一份授权 —— 把对象传来传去没问题，别指望「一个对象一个账号」。
- 生命周期由易语言自动调（构造 / 复制 / 析构）；**析构会停掉由本对象启动的自动刷新线程**，
  宿主不用记得收尾。
- `绑定事件回调` 的回调形如 `子程序 (整数型 事件码) 返回 整数型`：返回 **1** 表示宿主已接管，库不再弹默认提醒。

## 4.5 数据类型与常量（和旧模块逐字段一致）

粘进工程的顺序：**先** `会员类型与常量.e.txt`，**后** `易语言兼容层.e.txt`。

- `会员类型与常量.e.txt`：照抄旧「通用程序接口」模块的 11 个 自定义类型
  （程序信息 / 备份设置 / 代理信息 / IP地址类型 / 服务器注册信息 / 授权信息 / 附加信息 /
  程序内部信息 / 错误信息 / 规则数据 / 规则类型），成员名、类型、数组维数、注释全部保持原样；
  旧 常量（校检文本、时间加密密码、密码文本1~4、oem文件密钥、登陆返回代码_*、授权验证结果_*）原样保留；
  旧 全局变量（全局_授权信息、全局_授权信息2、全局_OEM、全局_程序信息、全局_程序内部信息、
  全局_北京时间、全局_连接COOKIE、全局_登录提示、全局_错误代码…）同名同类型，统一给成 公开 好让兼容层模块写入。
  窗口对象（全局_启动窗口/全局_启动封面）和 类_新接口、远程数据_模块版 这类工程内对象不在本文件里，留在原工程。
- 新增常量：`会员码_*`（接口错误码，如 会员码_机器码不符可换机 = "4001"）、
  `会员事件_*`（事件码）、`会员页_*`（界面初始页）、`会员状态_*`（ok/trial/expired/frozen/none）。
- `易语言兼容层.e.txt`：只剩子程序。`刷新会员信息()` 填 授权信息 的 13 个成员（含 附加信息 结构）并同步一份到
  全局_授权信息2；`刷新OEM信息()` 按旧类型把网址类成员给成 **字节集**、主题色给成 **整数**、
  程序设置用 `置代码()` 灌 JSON；同时回填 全局_程序信息 里能对上的成员（接口地址、是否可用、
  是否开启注册功能、是否开启卡密、首页URL、内嵌框架1/2URL、购买提示、软件标题、IP地址）。
  旧 授权信息 结构里没有的字段（绑定机器码、功能版本名称、剩余换机次数…）用 `取授权字段("bind_mac")` 取。

两处与旧模块**故意不同**，都写死在注释里：

1. `代理信息.软件图标` 恒为空字节集 —— 新支持库自带横幅图，不再从 OEM 文件取图标。
2. `程序信息` 里 appset/更新相关成员（最新版本号、强制更新、MD5列表、更新地址列表、封禁IP…）保持默认空值 ——
   新后端不提供这些，自动更新仍走原来的更新模块。

为补齐旧 `附加信息` 口径，后端在授权数据里多返回 `attr`（cor_last_actdate、
ac_function_catalog_duedate、ac_function_cc_duedate、ac_sp1、ac_sp2、ac_sp_max、
ac_sp_v3_1、ac_sp_v3_2、ac_sp_v3_max）与 `ip` / `ip_location`；
限速参数读后台「接口配置」里的同名键，不配就是 0=不限速。
客户端用 `会员_取附加信息(键名)` 取值，键名留空返回整段 JSON。

## 5. 界面（会员_显示注册窗口）

一个模态向导窗口（客户区 656×558）：顶部品牌横幅（素材从旧版窗口里取出后 base64 内嵌，不依赖外部文件），
中间一张白色卡片放当前页，底部一行文字链接（注册教程/说明、官方网站、联系方式）。
「退出本机账号」**默认不显示**，只有 `会员_初始化` 最后一个参数给真才出现（命令 `会员_退出本机账号` 本身不受影响，宿主想自己放按钮随时能调）。
输入框、按钮、验证码图片全部自绘，宿主带不带 comctl32 v6 清单都长一个样。

`初始页`：0=登录/注册首页 1=登录账号 2=填写注册信息 3=开通授权 4=授权成功 5=激活序列号 6=换机验证。

- 首页：登录（主按钮）/ 注册账号 两个入口，右侧各配一句说明。
- 登录账号：邮箱 + 只读机器码（带复制）+ 协议勾选，整宽「登录」主按钮。**不放换机入口**：机器码不符（登录不上）时直接弹换机验证小窗，输序列号通过即绑定并扣次数；次数用完由服务端返回「请联系客服处理」并弹窗带客服QQ。
- 填写注册信息：邮箱、手机号、关联账号、QQ、获取渠道下拉、图形验证码 + 协议勾选；提交时盖一层「请稍候，正在提交注册信息…」遮罩。
- 开通授权：回显注册邮箱与机器码，内嵌购买区（「打开购买页面」用默认浏览器打开 `shop_home`），下面是 免费试用 / 激活序列号 / 刷新授权 三个动作。注册成功停在这一页，**不再自动开通试用**（与旧版一致，试用要用户点）。
- 授权成功：绿色对勾 + 到期时间 + 授权须知 + 「开始使用软件」。
- 激活序列号 / 换机验证：序列号 + 图形验证码；换机页顶部红字写明「还剩 N 次换机机会」，通过后当场换机并登录，次数用完时接口直接返回 4002 提示，不进换机页。
- 验证码图片点一下换一张（GDI+ 解码，不写临时文件）。

**序列号激活与换机验证是独立小窗口**（520×300，类名 `CxAhKeyWindow`），不占向导页号：
向导里点「激活序列号」、或登录返回机器码不符时，都会把这个小窗模态弹在向导之上，关掉即回到原页面。
命令层也能单独调用：`会员_显示续费窗口`（激活）、`会员_显示换机窗口`（先申请换机再弹验证窗）。

## 5.1 用户中心（`会员_显示用户中心`）

独立窗口（620×470，类名 `CxAhUserCenterWindow`），登录后随时可开，打开时自动先刷一次授权：

| 区块 | 内容 |
| --- | --- |
| 状态行 | 授权正常 / 免费试用中 / 已到期 / 已被停止使用 / 尚未开通，账号绑的不是本机时行尾追加提醒 |
| 登录账号 | 当前账号邮箱（只读框，可选中复制） |
| 授权版本 | `function_name` + 版本代号 `function` |
| 本机机器码 | 初始化传入的机器码 + 「复制」按钮 |
| 到期时间 | `due_date`，试用与已到期会标注 |
| 剩余换机次数 | `change_left` / `limit_change` |
| 已开通的选配功能 | 后台 `user_function` 里的每条：名称 + 到期时间（或"长期有效"），已停用的标注「（已停用）」 |
| 动作 | 打开购买页面（用渠道 `shop_home`，没有则退回 `buy_text`/`home`）、激活序列号（弹独立小窗，激活完自动刷新）、刷新授权、关闭 |

命令层取数：`会员_取选配功能` 返回每行「名称|到期时间|1」（末位 1=可用 0=已停用），
`会员_取授权信息("function_names")` 返回可用功能名的顿号串，`会员_取授权信息("functions")` 同 `会员_取选配功能`。
返回真表示关闭时账号可用。

## 5.2 事件与自动刷新（不用自己写时钟）

三种取事件方式，任选或并用：

| 方式 | 命令 | 说明 |
| --- | --- | --- |
| 窗口消息（推荐） | `会员_设置事件窗口(窗口句柄, 1024)` | 库 `PostMessage` 到你的窗口，`wParam` 就是事件码。跨线程安全，自动刷新线程产生的事件也能收到。 |
| 子程序回调 | `会员_设置事件回调(子程序指针)` | 回调形如 `子程序(整数型 事件码) 返回 整数型`，**返回 1 表示已接管**（库不弹默认提醒），返回 0 交给库。**只在登记它的那个线程上触发**：自动刷新线程产生的事件不走回调，只走窗口消息和队列，避免从工作线程扎进宿主界面代码。传 0 取消。 |
| 只收窗口消息的宿主 | `会员_事件已接管(事件码)` | 窗口消息没有返回值，收到事件后如果宿主自己处理完了，调这条告诉库，库就不再补默认提醒。 |
| 轮询队列 | `会员_取事件` / `会员_取事件数` / `会员_清空事件` | 每次弹出一条最早的 JSON：`e` 事件码、`n` 英文名、`t` 时间、`d` 详情（含 code/msg/email/status/due_date）。 |

事件码（`会员_取事件名(码)` 返回可直接显示的中文）：

| 码 | 名字 | 触发时机 |
| --- | --- | --- |
| 10 / 11 | login_ok / login_fail | 登录成功 / 失败（含机器码不符 4001、次数用完 4002） |
| 20 / 21 | register_ok / trial_ok | 注册成功 / 免费试用已开通 |
| 30 | activate_ok | 序列号激活成功 |
| 40 | change_ok | 换机成功 |
| 41 | mac_changed | **账号被改绑到别的电脑**，本机授权已收回（库同时把 `授权状态` 置为 `revoked`，但保留账号与换机次数，用户还能换机换回来） |
| 50 | auth_refreshed | 授权信息刷新完成（手动刷新与自动刷新都发） |
| 51 / 52 | auth_expired / auth_frozen | 授权到期 / 账号被停止使用 |
| 53 | auth_lost | 原本可用现在不可用，功能要立刻收回去 |
| 54 | soon_expire | 授权快要到期，`d.days` 是剩余天数；同一天只提一次 |
| 90 | unreachable | 连不上授权服务器（网络问题，**不**据此收回功能） |
| 60 | logout | 退出本机账号 |
| 70 / 71 | auto_started / auto_stopped | 自动刷新启停 |
| 80 | window_close | 会员窗口被关闭（d.authorized 表示关闭时是否已拿到授权） |

自动刷新：`会员_启动自动刷新(间隔秒, 窗口句柄, 消息号)` 在库内起一个线程按间隔调 `auth.refresh`，
到期/冻结/失效都会发事件；重复调用只改间隔并立刻刷一次；`会员_取自动刷新间隔` 返回 0 表示未启动；
`会员_停止自动刷新` 会等工作线程退出。支持库卸载时自动停线程。

典型接法（易语言）：初始化后 `会员_设置事件窗口(取窗口句柄(), #WM_会员事件)`，
在窗口消息处理里按 `wParam` 分发；或直接 `会员_启动自动刷新(300, 取窗口句柄(), #WM_会员事件)`，
收到 51/52/53 就弹续费提示并锁功能。

### 默认提醒（宿主没接管时库替用户说一声）

`会员_设置提醒策略(自动弹窗, 到期前天数)`，默认「真 + 提前 3 天」。库会在这种情况下自己弹窗：

| 事件 | 没接管时库做什么 |
| --- | --- |
| 41 账号被换到别的电脑 | 弹「您的账户已更换到其他电脑，即将退出。如需继续在本机使用，请重新登录并按提示完成换机验证。」，同时收回本机授权 |
| 54 授权快到期 | 弹「您的授权还有 N 天到期（到期时间 …），请及时续费。」，同一天不重复弹 |

## 7.1 壳子演示程序与界面实测抓出的四个真 bug

`build_demo.bat` 产出 `out\cx_demo.exe`：按宿主正规顺序装载 `cxah.fne`（`GetNewInf` → `NL_SYS_NOTIFY_FUNCTION` → 按命令名取实现），
初始化后真开会员窗口，关窗后打印授权结果。用它截图肉眼验收，抓到四个必须修的问题：

1. 窗口创建后没调 `ShowWindow(SW_SHOW)` —— 真机上是隐形窗口。
2. 字段标签（原来 id 传 0）与底部链接行不属于任何面板分组，`ShowPanel` 不会显示 —— 已改成**控件创建时就登记所属面板**（`Win::panelIds`），漏显这一类问题从根上消掉。
3. `EDIT` 没给 `WS_EX_CLIENTEDGE` —— 白底上编辑框等于隐形，看着像少了六个输入框。
4. 窗口宽 520 放不下右上角「序列号续费」，被裁 —— 加宽到 544。

另外宿主侧两个坑记着：`FindWindowW` 会抓到**别的进程**开的同名窗口（演示程序与宿主同时跑时踩过），必须按 `GetCurrentProcessId()` 过滤；
子控件在 `CreateWindowExW` 返回后才创建，要轮询到控件齐了再断言。

1. 窗口创建后没调 `ShowWindow(SW_SHOW)` —— 真机上会是个「听得见点不动」的隐形窗口。
2. 标题与底部链接行（复制机器码/购买页面/官网/帮助/协议）不属于任何面板分组，`ShowPanel` 不会显示它们，
   必须走 `ShowPersistent()`，否则这一排按钮永远不可见。

宿主侧两个坑记着：`FindWindowW` 能在子控件创建之前就拿到窗口句柄，要轮询到控件齐了再断言；
两个宿主不能共用同一份邮箱/序列号夹具，各自 `host_seed.php` 一次。
